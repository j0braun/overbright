Load times: the measurements behind docs/perf-budget.md "Load times".
Binaries: perf.sh build (the measured profile). "discrete GPU" / "integrated GPU": the two GPUs of the reference desktop.
The machine was shared during every series: other builds and comparisons ran (load average in each table's notes,
16 hardware threads), and another program kept the discrete GPU's queue busy (its busy counter 72-100 %). The
integrated GPU was otherwise idle. Wall times on the discrete GPU carry that program's turns; see the text.
dgpu = the discrete GPU, igpu = the integrated GPU; orig / low / med / high = Original and the three Enhanced levels;
any = no level (the start-up).

== 1. What a player waits for (this tree; ms, median [min..max], 5 runs) ==
warm: --bench boot, --bench transitions with the main menu's preload first (each span: the load call and its first
frame drawn and done on the GPU). empty: a fresh cache folder for the game and for the driver's shaders per run;
--bench boot, explore, race, race with the first Quick Race drag track (load_ms and the first frame apart).
