The start's and the menus' waits (docs/start-and-menus.md): the shipping game (built without the developer harness) in a
window on a private Xvfb, sandboxed (bwrap: no sound device, its own data, cache and driver shader cache folders), keys
pressed with xdotool as a player presses them, the times from the game's own wait lines (docs/waits-log.md, "from the
key", ms). Tour C: the boot (Enter per movie), the title (Enter once it is taken), the profile message, Career, Resume,
the garage (Crib), Car Select and back, Change Parts (a category, a parts list) and back, Return to Explore Mode (yes),
free roam, pause / resume, Photo Mode (play rows), Jump to Garage (yes), free roam again. Tour F: the boot, Options (a
page and back), Customize (the car lot, a category, a parts list, back), Quick Race (mode, track, options, car lot,
transmission), the race (start scene skipped), pause / resume, Restart, Quit.
Settings: "play rows" = a play setup's options.txt as it is (every Graphics row up; 3840x2160 on the discrete GPU,
1920x1080 on the integrated one); "Original" = no options but the resolution (1920x1080). Each run under the measuring
lock of its GPU (one run a lock hold); base = the base tree's binary, new = this tree's.
States: hot = the game folder, the cache folders and the binary read right before the run (their pages in the OS cache);
warm = the caches on disk, the files as this machine's page cache left them (it held ~11 GB beside other programs'
builds and often dropped them); cold = the game folder's and the caches' pages dropped (posix_fadvise DONTNEED); first =
a new cache folder and a new driver shader cache, the files' pages dropped. Load average at the runs' starts 12–47 on 16
threads (median 22); the discrete GPU's busy counter 0–97 % (another program). Medians [min–max] of 7 runs (tour F 5)
unless "n a/b" says otherwise. A measuring lesson: the harness's NFSU2_INPUT_LOG on ext4 made the main thread wait up to
0.6 s in the journal inside a measured wait (do_get_write_access): the log is on tmpfs in every run here.

Builds: "new" in the first three tables is an earlier build of this tree (new2: the scene ahead made its renderers and
their pipelines); the final build is new4 (below). The start and free roam parts are the same code in all three.
