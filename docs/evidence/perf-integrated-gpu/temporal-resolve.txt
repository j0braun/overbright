# The temporal resolve on the integrated GPU: attribution, candidates, the kept change
# Method: scripts/passes.sh (arms interleaved, order rotated per rep), 5 reps, --bench racing / race 200 frames
# (integrated) or 300 (desktop), 1920x1080 unless named, Anti-Aliasing Native, the levels of scripts/levels.sh.
# scripts/pairs.py: per rep the arm against the base of the same rep (frame = GPU busy median of the run,
# pass = "graphics: temporal resolve" or, for the candidates, every "graphics: temporal" row summed),
# then medians and the pairs' range. Measuring builds: the base tree with one part of temporal.wgsl replaced
# (named per block); they are not in the tree.
# Arms: null = resolve returns the centre load; onecol = the cross's colour from the centre only (4 loads,
# tone maps, YCoCg less); onedep = depths from the centre only; notm = no tone map per sample; noycc = no
# YCoCg per sample; noexp = weights without exp (changes the weights: its Performance row is not a cost);
# nostat = no moments / min / max; nocar = car loop count 0; nohist = history one load, no Catmull-Rom;
# noclip = no box clip. cs1 = the same shader as compute (8x8), history by storage, copy to the scene;
# cs2 = cs1 with the cross from workgroup memory; cs3 = cs1 with the per-tile car test (the kept form);
# fsgate = fragment pass, car loop skipped outside the cars' rectangles' union.
