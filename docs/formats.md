# NFSU2 world formats — what is known and how we know it

Target: `SPEED2.EXE` (sha256 `8f6a9ae2…2a297`) and the data shipped next to it.
Each claim is tagged:

* **verified** — checked against the whole data set, e.g. every record parses,
  every reference resolves, or a computed value matches a stored one.
* **inferred** — consistent with the data, but not yet traced in the executable.
* **open** — not known yet.

The text is split into chapter files in [docs/formats/](formats/), each small enough for GitHub to render
(a file over its size limit shows only as raw text). This page is their index: every chapter, every section
with its heading text unchanged (a reference such as `docs/formats.md "Sky"` is a section named here), and
the sections by the SPEED2.EXE addresses they cite. A new section goes into the chapter of its subject; rerun
`scripts/docs/formats_index.py` afterwards (`--check` also fails when a chapter passes 300 KB).
